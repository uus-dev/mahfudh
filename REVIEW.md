# Review checklist for the Arabic specialist

All 32 units and 12 supporting concepts are first drafts. Everything needs checking; the points below are where the drafting flagged uncertainty or a convention choice. When a unit is approved, set its `review_status` and bump `revision` (or `target_version` if what must be memorised changes).

## Qur'an quotations — verify wording against a mushaf
- D01: إِنَّ اللّٰهَ غَفُورٌ رَحِيمٌ
- C07: 112:3 · C08: 2:197 · C11: 12:31 · C12: 12:29 · D03: 4:96, 12:85
- Tashkīl is written in ordinary script, not mushaf orthography.

## Display conventions to decide
- Hamzat al-waṣl: currently written with a visible vowel in tables (اُكْتُبْ / اِجْلِسْ) and as a bare alif mid-sentence.
- Transliteration style for unit titles (currently academic with macrons: *inna wa-akhawātuhā*).
- “Typical English” columns repeat English in both language fields (D01, B01 …).

- **A02** Uses جرّ (Baṣran) with خفض noted; template set to paradigm.
