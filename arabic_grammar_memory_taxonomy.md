# Arabic Grammar Memory Reference — Master Taxonomy

**Version:** 0.1  
**Scope:** A proposed bilingual reference of bounded grammatical lists, paradigms, patterns and compact rule packages; not a curriculum.  
**Units:** 100  
**First release:** 32 units

> This is a proposed taxonomy. Teaching content and answer keys require editorial approval.

## Stage definitions

- **Foundation:** Initial reference material; not a course level.
- **Core:** Common follow-on material; order depends on the student's course.
- **Further:** Specialist, extended or more conditional material.

## Contents by category

- **Foundational memory maps** — 8 units
- **Pronouns and closed noun sets** — 8 units
- **Particles and grammatical operators** — 13 units
- **Governing families** — 9 units
- **Noun endings and plural patterns** — 11 units
- **Verb conjugation and endings** — 9 units
- **Word-formation patterns** — 17 units
- **Weak and irregular verb models** — 9 units
- **Compact construction rules** — 10 units
- **Numbers and counted nouns** — 6 units

## Tracking specification

### unit_id

Stable identifier, such as D01.
**Constraint:** Progress attaches to the unit, not each place it appears in navigation.

### unit_version

Version of the specific memorization target.
**Constraint:** When a list or rule changes, retain history and flag that review is needed.

### status

Not started / Learning / Memorized.
**Constraint:** Self-reported recall only; never presented as verified grammatical competence.

### last_reviewed_at

Optional date of the most recent self-review.
**Constraint:** A factual date, not a claim about retention.

### scope_label

Core list / Extended list / Selected patterns / Conditions.
**Constraint:** Define exactly what the checkbox covers; never 'all Arabic plurals'.

### subtargets

Optional list / meanings / effect / conditions.
**Constraint:** Use only where a unit is too coarse; do not require a quiz engine.

### source_convention

Identified source and editorial convention.
**Constraint:** A student can see why their teacher's list or terminology differs.

### language_preference

Arabic / English / Both.
**Constraint:** Independent of Foundation, Core or Further stage.

### page_slug

Stable parent page.
**Constraint:** A page can contain multiple separately trackable units.

### prerequisites

Helpful knowledge links, not mandatory locks.
**Constraint:** This is not a sequential course or a required learning path.

### related_unit_ids

Cross-links to the same underlying units.
**Constraint:** Do not duplicate progress across indexes or case-sign views.
